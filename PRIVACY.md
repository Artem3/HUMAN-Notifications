# Політика конфіденційності HUMAN Notifications

Дата набуття чинності: 21 вересня 2026 року.

HUMAN Notifications — неофіційне розширення Chrome для перегляду сповіщень, домашніх завдань і оцінок із HUMAN.

## Які дані обробляються

Розширення обробляє email і пароль HUMAN, дані сеансу HUMAN, сповіщення, домашні завдання, оцінки та локальний діагностичний журнал.

## Для чого

Дані потрібні лише для входу до HUMAN, автоматичних перевірок і показу інформації в Dashboard. Розширення не містить реклами й не використовує аналітику.

## Зберігання та передавання

Дані зберігаються локально у профілі Chrome. Запити надсилаються через HTTPS лише до `api.human.ua`, щоб отримати дані HUMAN. Розробник не отримує ці дані й не передає їх іншим сторонам, окрім HUMAN, необхідного для роботи розширення.

Пароль не відображається в Dashboard і не включається до завантаженого діагностичного журналу. Журнал можна передати розробнику через GitHub Issue лише за власним рішенням користувача.

## Видалення даних

«Очистити все» видаляє локальну історію, оцінки та журнал, але залишає дані входу для автоматичного входу. Щоб видалити всі дані розширення, видаліть HUMAN Notifications у Chrome.

## Контакт

Запитання щодо конфіденційності можна поставити через [GitHub Issues](https://github.com/Artem3/HUMAN-Notifications/issues).
